# Справочные материалы — не в публичном репозитории

Эта папка гитигнорнута (`materials/*` в `.gitignore`, кроме этого файла)
— репозиторий на GitHub публичный, а здесь лежат внутренние документы
заказчика (цены, условия, стратегия). Передаётся отдельно — вместе с
остальной папкой проекта на флешке или другим приватным каналом, не
через git push.

Если этой папки нет (например, свежий `git clone` без материалов) —
взять актуальные версии у заказчика напрямую и положить сюда с теми же
именами файлов, чтобы ссылки в `AGENT_START_HERE.md` не сломались.

## Что должно здесь лежать

- **`ZORIN_база_для_разработчика_сайта_2.docx`** — основной бриф
  заказчика: карточка компании, позиционирование, продукция с MOQ/
  сроками/ценами, готовый FAQ, карта поисковых запросов по страницам
  (раздел 13), стратегические решения. Главный источник фактов для
  всего контента сайта — при любой правке текста сверяться с ним, не
  выдумывать цифры.
- **`ZORIN_semantic_core.xlsx`** — 167 поисковых запросов в 15
  кластерах от заказчика, каждый смаппен на целевую страницу.
- **`лого-партнеров-исходники/`** — необработанные фото логотипов
  партнёров (Сударь, Stenser, Стрекоза, Melon, Zolla, KiK), присланные
  заказчиком. Обработанные версии уже лежат в
  `public/images/partners/*.png` и подключены через `src/lib/clients.ts`
  — эта папка нужна, только если логотипы придётся переделать заново
  (другой формат, другое качество).

## Важно

Вектор логотипа ZORIN — **не здесь**, он уже в самом репозитории:
`public/logo/zorin-logo.svg`, используется через `src/components/Logo.tsx`.
